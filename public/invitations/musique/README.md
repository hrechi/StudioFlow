# Invitation music

Drop royalty-free MP3 files here with exactly these names. A track whose file is missing is simply
not offered in the editor, and never played on the public page.

| File | Shown as |
| --- | --- |
| `piano-doux.mp3` | Soft piano |
| `valse.mp3` | Waltz |
| `fete.mp3` | Party |
| `oud.mp3` | Oud |
| `lounge.mp3` | Lounge |
| `berceuse.mp3` | Lullaby |

Keep each file short (1–2 minutes, it loops) and light (about 1–2 MB, 128 kbps), and check its licence
allows use on a commercial website. The list lives in `src/modules/invitations/invitation.types.ts` (`MUSIQUES`).
